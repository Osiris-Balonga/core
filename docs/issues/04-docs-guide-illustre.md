## Contexte

`CONTRIBUTING.md` suppose qu'on sait utiliser Git en ligne de commande. Beaucoup de contributions (données, docs) peuvent se faire **entièrement depuis l'interface GitHub**, sans rien installer.

## À faire

Créer `docs/premiere-contribution-navigateur.md` avec captures d'écran :

1. Forker le dépôt
2. Modifier un fichier dans l'éditeur web de GitHub
3. Créer une branche et un commit au bon format
4. Ouvrir la Pull Request vers le dépôt principal
5. Répondre à une demande de modification

Ajouter un lien vers ce guide dans `CONTRIBUTING.md`, section 2.

## Critères d'acceptation

- [ ] Captures en PNG compressé (moins de 200 Ko chacune) dans `docs/images/`
- [ ] Aucune information personnelle visible sur les captures (email, notifications)
- [ ] Testé par une personne qui n'a jamais ouvert de PR : elle a suivi le guide sans aide
