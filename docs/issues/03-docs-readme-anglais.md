## Contexte

Le README est en français. Une version anglaise ouvre le projet aux développeurs d'Afrique anglophone et aux contributeurs internationaux.

## À faire

1. Créer `README.en.md`, traduction fidèle de `README.md` (pas de traduction automatique brute : relisez et adaptez).
2. Ajouter en tête de chaque README un lien vers l'autre langue : `🇫🇷 Français · 🇬🇧 English`.
3. Garder les exemples de code identiques.

## Critères d'acceptation

- [ ] Toutes les sections sont traduites
- [ ] Liens croisés en tête des deux fichiers
- [ ] Relu par une seconde personne (mentionnez-la dans la PR)

Parfait pour un premier passage par le workflow fork → PR, quel que soit le parcours.
